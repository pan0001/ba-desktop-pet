# 原始家具适配

## 当前范围

- 1015 件带纹理的游戏原始家具，对所有已导入学生开放摆放。
- 122 个候选组合中，108 组开放专用互动，涉及 103 个学生/服装、101 件家具。
- 12 组超出固定桌宠窗口，1 组角色睡姿低于地面，1 组缺少家具动画：仅保留摆放。原因在 `tools/game-assets/furniture-overrides.json` 和清单的 `missingAnimations`。
- 36 个 prefab 导出失败、1 个没有纹理：未加入选择列表。

设置 → 语音与家具 → 桌面休息角：最多同时添加 6 位学生（包含当前伙伴）、独立摆放 6 件家具。学生各自散步、拖动和抛掷，家具可单独拖动，离开后仍留在桌面。保存学生名单和摆放位置，重启重新建立互动。

兼容学生在家具空位附近停留 0.6 秒后自动互动。不兼容、已占用、拖动、下落、特殊动作和暂停状态不会抢座。互动约 60 秒后继续活动；双击入座学生或设置中的「离开家具」可提前离开，15 秒内不重新入座。收起家具会让所有学生返回桌面；加载失败或超时保留原学生。

当前开放 5 种多人家具：街机 2 人、会长办公桌 2 人、冰淇淋桌 2 人、打西瓜 2 人、祈祷长椅 3 人。花架的遥香两套服装动作虽然位置不同，但扫过的姿势重叠，共用一个名额。模型根骨骼采样及人工画面检查定义在 `assets/furniture/seats.json`。并非任意学生都有任意家具的专用动作；悬停家具卡片查看支持名单。

家具列表保留图片、搜索、每页 18 项、当前学生专用互动筛选。名称暂用中日英分类及稳定编号，非官方译名。旧版本的附身家具在启动时转为独立摆放。

## 渲染与动画

原始 GLB 按 SHA-256 验证，模型与贴图原样保留。静态网格的 Y-up 已烘焙；骨骼 prefab 需要补齐 FBX 根节点坐标，避免重复旋转。蓝色懒人沙发另有经过画面核查的轴向修正。专用动作按学生、动作阶段匹配家具动画，各 AnimationMixer 共用场景动画时间。

互动角色与家具共享原始坐标、相同比例及转向，不做行走时的根骨骼位移抵消；固定家具基底高度接地，避免按每帧角色姿势抬升家具。装饰家具以有限尺寸单独摆放，略微倾斜呈现，让地毯和薄墙板在固定正面镜头下可见。角色相机、正常尺寸及抓取支点不因家具改变，头发不加入碰撞。

独立家具使用 `scripts/furniture-scene.js` 的生产渲染场景。同一家具、所有入座学生共用深度缓冲、原始坐标和动画时钟；沿用学生的材质、面部、光环修复及灯光、描边。缩放以参考学生站立高度确定，不随入座人数或姿势重新拟合。配对专用动作与家具阶段一起切换。单独摆放时不加载隐形学生模型。

主进程按真实 WebContents 路由各学生的物理和交互，座位先预留，渲染成功后才隐藏原窗口，避免重复和学生消失。隐藏、暂停、锁屏冻结互动时间。主学生保留主动邀约；额外学生暂不触发主动邀约，仍可点击、摸头和播放日常语音。

家具只在选择时加载；迟到的解析结果立即释放。收起清理几何体、贴图、骨骼、动画和描边资源。

## 验证与复现

`tools/game-assets/review-furniture.cjs` 启动真实 Electron 桌宠，使用其镜头、材质、灯光、物理和动画，输出每件家具的原始画面、边界、运行状态及代码指纹。1015 件摆放家具均完成加载和截帧，全部 122 个候选组合有检查记录，失败组合显式停用。自动边界检测不代表任何时刻都没有细微穿模。

`tools/game-assets/build-furniture-gallery.py` 生成 `test-results/furniture-preview/index.html`，可以搜索、放大检查。预览卡只裁切和排版原图，不替换渲染设置。

```powershell
node --test tests/*.test.cjs
node tests/furniture-desktop.cjs
node tests/furniture-lifecycle.cjs
node tests/scene-desktop.cjs
node tests/scene-multiplayer.cjs
node tools/game-assets/inspect-furniture-seats.cjs --all --write
node tools/game-assets/review-furniture.cjs decor
node tools/game-assets/review-furniture.cjs interactions
python tools/game-assets/build-furniture-gallery.py
```

桌面测试覆盖屏幕边缘、真实鼠标抓取、支点误差、点击后保持静止、暂停选家具、快速切换竞态、缺资源恢复、角色动作匹配、缩略图和中日英界面。打包逐字节校验所有家具 GLB 与预览图，保留既有光环 OBJ 校验。

## 限制

大型舞台、墙面和泳池的部分专用组合仍待镜头与场景布局适配；睡床的 457 号角色需要重新对齐。GLB 不含完整 Unity 粒子系统、游戏机屏幕程序或专用 shader。家具不会吸附或自动跟随其他应用窗口；拖到窗口边缘后，学生脚下位置足够接近才能互动。多人动画使用已验证的原作角色组合，不会为缺少动作的学生合成新动作。
