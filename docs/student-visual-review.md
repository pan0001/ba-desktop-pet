# 学生实际渲染预览

预览使用 `tools/game-assets/review-students.cjs` 启动打包后的 Windows 桌宠，通过仅在 `--test-mode --measure-pet` 启用的检查入口驱动当前人物。没有另建 Three.js 场景，也没有替换相机、灯光、材质、描边或动画播放器。

- 角色尺寸：360（默认值）；物理开启；家具关闭。
- 为稳定截图，关闭自动行走、主动事件、语音和互动粒子，由检查入口触发行走、抱起和落地状态。
- 每个模型保存待机、行走、抱起、倒地 / 等待、起身五张完整窗口截图。六栏预览中的眼睛 / 刘海特写裁自同一张待机截图，不重新渲染。
- 截图前隐藏短暂的操作提示气泡，未改动模型画布。
- 卡片记录源模型 SHA-256、打包归档 SHA-256、实际动画名、动作时间、窗口尺寸和边界。原始截图保留透明背景。
- “已生成”只表示取得预览，不表示人工检查通过。静态取样不替代动作全过程检查。自动提示会如实保留，例如道具或身体超出实际窗口。

## 生成与查看

先运行 `npm run pack`，然后：

```powershell
node tools/game-assets/review-students.cjs
node tools/game-assets/build-review-gallery.cjs
```

也可在第一个命令末尾传入模型编号列表，例如 `227,308`。通过 `BA_REVIEW_EXE` 可指定另一个已打包程序。

打开 `test-results/student-preview/index.html`。页面无需网络，支持中日英姓名 / 编号搜索、图片放大、完整原图、检查状态与备注、意见 JSON 导出。生成器可接收目标文件夹参数。预览与截图保存在被 Git 忽略的 `test-results` 下，不会进入安装包。

## 此轮已修正的检查基础

- 原独立预览场景没有按桌宠的模型尺寸归一化，产生了眼睛与刘海的深度冲突假象。它的图片不作为实际渲染通过依据；以当前打包程序截图为准。
- 日富美、佳代子、朱莉收起武器时，极小武器节点错误拉大人物边界。现在该三种武器仅在真正收起时不参与边界；展开时仍计入完整尺寸。
- electron-builder 默认排除 `.obj`，使未花和实梨的补充光环遗漏。现在明确包含 Wavefront 资源，打包后逐文件校验内容，并检查程序没有光环回退警告。

目前目录为 280 个模型 / 276 个角色与服装。古书馆仍无可用本体的 5 项不伪造预览：霞（泳装）、叶莲娜、安娜、心、琴音。
