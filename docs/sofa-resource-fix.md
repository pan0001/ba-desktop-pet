# 游戏开发部沙发旋转修复（2026-09-27）

1.13.0 的沙发互动动画 `my_gamedevdept_01_sofa_01_Aris_Original_01` 含有最外层摆放节点的旋转轨道：约 16.36 秒内绕 X 轴从 0 转到 300 度。桌宠直接播放这条轨道会使整张沙发侧翻。爱丽丝的内部动作本身没有相同的整体旋转。

修复仅去掉该片段中家具最外层节点的 rotation 通道。网格、贴图、蒙皮及内部骨骼动画二进制数据保持不变；源 SHA-256 与修复记录保存在家具目录中。导入工具也应用同一修复，避免重新解包时恢复错误轨道。

这是资源更新，不改变 1.13.0 程序版本。只有 `furniture-seats` 包发生变化，下载量为 14,944,390 字节。原资源包保留在 GitHub，新的资源目录在新包上传并校验成功后发布。

使用方式：收起旧沙发，在设置中点击「检查资源更新」，然后在「语音与家具」里重新选择「游戏开发部沙发」；界面会下载更新后的座椅资源。无需重新安装程序或下载学生。

验证：实际生产渲染复现侧翻；修复后跨两轮完整互动采样 171 帧，家具外层旋转为零，内部动作仍在播放。已用已发布的 1.13.0 程序和隔离测试存档验证旧资源检测、仅下载变化资源包以及家具自动重新加载。
