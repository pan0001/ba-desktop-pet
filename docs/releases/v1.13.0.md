# 1.13.0 · 按需下载正式版

程序采用轻量安装包。首次启动选择界面语言，然后在角色目录点击需要的学生，从 GitHub 下载该角色模型及现有配音；不必一次下载全部学生。

- 目录包含 276 个角色／换装、280 个模型，支持中文、日文、英文名字和搜索，默认日语配音。
- 模型与语音分别打包。检查资源更新后，只下载变化的资源包；已下载内容可离线使用。
- 家具按类别下载，支持独立摆放、同时 6 位学生和 6 件家具，以及适配家具的双人／多人互动。
- 支持下载取消、失败重试和 SHA-256 校验。移除下载资源保留好感度与设置。
- 保留鼠标支点拖拽、惯性抛掷、发丝物理、情绪特效、语音字幕、主动邀约和养成系统。
- 修复预览版后续升级到正式版的版本判断。

Windows 安装包约 224 MB，安装后约 521 MB；爱丽丝和妮露合计额外下载约 12.6 MB，解压后的资源约 19 MB。不同平台体积以实际下载文件为准。

## 下载与升级

- Windows x64：Setup-x64.exe 为安装版，Portable-x64.exe 为免安装版。
- Apple 芯片 Mac：macOS-arm64.dmg；Intel Mac：macOS-x64.dmg。另附 ZIP 包。
- 现有正式版可以在「检查更新」中发现 1.13.0；Windows 安装版支持程序更新下载，其他版本按界面提示下载替换。
- 从完整版升级后，如没有资源缓存，需要重新下载所选学生一次。好感度和设置保留。
- 资源缓存位于应用用户数据目录的 resources 子目录，不随程序替换而删除。

Windows、Apple 芯片 Mac 和 Intel Mac 的安装包来自同一源码提交，构建及打包运行检查通过后发布。所有附件附 SHA256SUMS.txt。程序未使用代码签名证书。
