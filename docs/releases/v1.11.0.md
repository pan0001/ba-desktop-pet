# BA 桌宠 v1.11.0

## 拖动修复

- 修复 Windows 125%、150% 等分数缩放下，慢拖和自主移动导致透明窗口累计变大、人物变大而尺寸设置不变的问题。
- 固定模型画布，避免系统对窗口尺寸取整时重新适配镜头，保持鼠标抓取点与人物一致。
- 移动不再不断放大任务栏附近的透明窗口，消除这一路径产生的重绘异常。

## macOS

- 新增 macOS 13+ 的 Apple 芯片（arm64）与 Intel（x64）版本，分别提供 DMG 和 ZIP。
- 原生读取窗口位置，支持窗口顶边与 Dock 上方行走。
- 适配菜单栏、Dock 重新打开、多个工作区和 Command 快捷键。
- 模型、日语语音、中文字幕、互动特效、动态嘴型、主动邀约及羁绊系统沿用同一套实现。

Windows 用户下载 Setup 或 Portable；Mac 用户选择对应芯片的 DMG，拖到 Applications。升级前先退出旧版。两种系统的存档均保留在各自用户数据目录。

Mac 使用临时签名，未配置 Apple Developer ID 签名和公证。Windows 版本也未使用商业代码签名证书。

Intel Mac 的 GitHub 构建机未提供 GPU，自动界面检查使用 SwiftShader 软件渲染；正式应用仍使用默认图形后端。Intel 实机的硬件渲染、多屏和全屏空间行为仍需在对应设备上体验验证。
