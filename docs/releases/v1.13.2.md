# 1.13.2 · 学院筛选、更新说明与性能优化

## 简体中文

- **按学院选择学生**：在「伙伴与活动 → 选择伙伴」按学院筛选，支持与名字搜索、仅已下载叠加。覆盖现有 280 个角色模型；切换分类不改变已选学生，支持中日英界面。
- **显示 GitHub Release 更新说明**：发现新版时自动打开更新页，显示对应版本的功能与修复内容。标题、列表和代码按格式展示，去掉独立 README 导航行；长说明可以滚动，未填写时明确提示。同一版本在本次运行中不会重复打断，下载后仍保留说明。
- **修复普通版时的模型**：隐藏错误叠加的战斗服部件与机甲，恢复女仆形态，避免面罩遮脸和错误取景；保留骨骼、面部贴图和正常动作。
- **减少重复语音目录加载**：每个学生只读取自己的语音条目，保留原声、字幕与语言回退；索引在打包时校验生成。
- **释放长期隐藏的模型**：隐藏或家具入座持续 30 秒后释放原桌面模型，显示或离座时重新加载。短暂隐藏及可见的暂停状态保留画面，羁绊与选择不受影响。

本机 Windows 同条件测试：六学生待机私有内存约下降 **8.6%**，长期隐藏后约下降 **35.1%**。单学生没有显示内存改善，CPU 结果不一致；这些数字不代表所有设备，也不代表显存。完整数据与限制见[性能报告](https://github.com/pan0001/ba-desktop-pet/blob/master/docs/performance-optimization.md)。

Windows 安装版继续优先增量下载，缓存缺失或差分失败时回退完整安装包。保留设置、好感度和已下载资源。本次模型修复在程序适配层完成，学生资源包没有变化，不需要重新下载学生。**已有 1.13.1 用户需要先升级程序，才能获得新的说明展示方式。**

## 日本語

- 学園別の生徒フィルターを追加。名前検索・ダウンロード済み条件と組み合わせられ、選択中の生徒は維持されます。
- 新バージョン検出時に GitHub Release の更新内容を表示。見出しやリストを整形し、README の単独ナビゲーションを除外します。同じバージョンの繰り返し通知を抑制します。
- 通常版トキのメイド姿に戦闘装備が重なる問題を修正。
- 音声データを生徒単位で読み込み、30 秒以上非表示のモデルを解放。再表示・家具から離れる際に復元します。

Windows インストール版は差分更新を優先し、必要に応じて完全版へフォールバックします。設定・絆・ダウンロード済みリソースは保持します。Mac とポータブル版は手動で入れ替えてください。

## English

- Add school filters to student selection, compatible with name search and downloaded-only filtering. Existing selections are preserved.
- Show the matching GitHub Release notes when a new version is found. Format headings and lists, omit standalone README navigation, and avoid repeated interruptions for the same version during a session.
- Fix combat outfit and mech parts overlapping normal Toki's maid model.
- Load voice metadata per student and release desktop models after 30 seconds hidden or seated in furniture. Restore them when shown or leaving furniture.

On one Windows test machine, six-student idle private memory fell approximately **8.6%**, and long-hidden private memory fell **35.1%**. Single-student memory did not improve and CPU results were mixed. These are not universal or VRAM claims; see the linked performance report.

Windows Setup still prefers differential downloads with a full-download fallback. Settings, bond progress and existing resource downloads remain intact. This release does not change student resource packs. Mac and portable builds require manual replacement.
