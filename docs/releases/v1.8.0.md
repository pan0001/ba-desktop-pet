# BA 桌宠 1.8.0 · Windows x64

非官方《蔚蓝档案》3D 桌面伙伴，下载后可离线运行，无需 Node.js 或原始资源目录。

## 下载

- **Setup-x64.exe**：安装版，向导中选择目录，为当前 Windows 用户安装。
- **Portable-x64.exe**：免安装版，双击后解压内置资源并启动。
- **SHA256SUMS.txt**：下载文件的 SHA-256 校验值。

## 功能

- 38 名学生、40 个模型形态，日常使用咖啡厅动作。
- 鼠标抓取点作为摆动支点，支持发丝惯性、上抛及左右抛掷。
- 桌面和窗口上自主行走，落地后随机起身或向老师求助。
- 日语原声与中文字幕，可切换中文配音；支持点击、摸头与挂机台词。
- 爱心、星光、汗滴等互动效果与原版情绪图标。
- 原版 UI 背景、按钮底纹和图标；角色搜索、声音与活动设置。
- 爱丽丝沙发和游戏机互动。

## 使用说明

升级前请通过托盘菜单退出旧版。设置保存在 `%APPDATA%/ba-desktop-pet/settings.json`，安装版与免安装版共用设置。关闭设置窗口不会退出桌宠；可从托盘菜单或设置页退出。
