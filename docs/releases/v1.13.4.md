# 1.13.4 · 学生气泡字幕跟随语言设置

## 简体中文

- **修复学生头顶字幕固定显示中文**：挂机、互动、摸头和邀约语音的字幕会按界面语言选择中文、日文或英文，多个学生窗口也会使用相同的语言设置。
- **字幕与配音独立**：选择英文界面仍可保留日语原声，中文配音也可以显示日文或英文字幕，不会因切换界面语言更换配音。
- **按语音编号匹配译文**：保留古书馆的中文及日文原文，并补充 [Schale DB](https://schaledb.com/) 的对应字幕，避免串到其他学生、服装或不同台词。当前 10,036 条配音记录中，10,009 条有日文字幕，9,636 条有英文字幕；缺少译文时会明确标注并显示原文。
- **验证与维护**：通过多学生、三语言的实际窗口检查及 124 项自动测试；字幕继续按学生加载，后续同步素材时会保留已匹配的字幕。

**更新方式**：Windows 安装版继续优先增量下载；旧缓存缺失或差分失败时自动回退完整安装包。设置、羁绊和已下载资源保留。本次只需更新程序，角色、语音音频和家具资源包无需重新下载。便携版与 macOS 请手动下载并替换程序。

## 日本語

- 放置中・ふれあい・なでる・お誘いのボイス字幕が中国語のままになる問題を修正しました。複数の生徒の吹き出しも、画面の言語設定に合わせて中国語・日本語・英語を表示します。
- 字幕と音声の言語は独立しています。英語の画面で日本語音声を使ったり、中国語音声に日本語・英語字幕を表示したりできます。
- 古書館の字幕・原文を維持し、Schale DB の字幕を完全な音声キーで照合しました。10,036 件の音声レコードのうち、日本語字幕は 10,009 件、英語字幕は 9,636 件です。翻訳がない場合は、その旨を明記して原文を表示します。
- 複数生徒・3 言語の実機表示チェックと 124 件の自動テストに合格しました。字幕は生徒ごとに読み込みます。

Windows インストール版は差分更新を優先し、必要に応じて完全版をダウンロードします。設定・絆・取得済みのリソースは保持します。生徒・音声・家具のリソースパックの再ダウンロードは不要です。ポータブル版と macOS は手動で入れ替えてください。

## English

- Fix speech bubbles always displaying Chinese. Captions for idle speech, interactions, petting and invitation dialogue now follow the Chinese, Japanese or English interface setting, including additional student windows.
- Keep caption and recording languages independent: use Japanese audio with an English interface, or Chinese audio with Japanese or English captions.
- Match subtitles by complete recording keys, retaining Kivo text and supplementing it with Schale DB captions. Of 10,036 recording entries, 10,009 have Japanese captions and 9,636 have English captions. Missing translations are explicitly labelled before showing the source text.
- Verified multiple student windows in all three languages and passed 124 automated tests. Captions still load per student, and subsequent asset imports preserve matched subtitles.

Windows Setup prefers differential downloads and falls back to a complete installer when required. Settings, bond progress and downloaded resources are preserved. Only the application needs updating; no student, audio or furniture resource packs need downloading again. Portable and macOS users should replace the application manually.
