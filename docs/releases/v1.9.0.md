# BA 桌宠 1.9.0 · 羁绊与日常照顾

新增「羁绊」页面：每名学生独立保存 1–10 级好感成长、心情、精力与饱腹。

- 点击、摸头、扶起和有效陪伴积累羁绊；同一学生编号的不同模型共用进度。
- 给点心、送礼物、一起玩、休息，配合原有咖啡厅动作、情绪图标和语音反馈。
- 今日三个小约定、可领取奖励、四项成就和最近照顾记录。
- 精力低时减少散步与自动语音；休息时恢复精力，保留原来的活动开关。
- 升级优先播放对应的原版羁绊语音和字幕；拖动、下落和求助时不抢动作。
- 冷却和每日次数保存到本地。离线不扣好感，隐藏、暂停和锁屏不计算陪伴。

## 下载与升级

`Setup-x64.exe` 为当前 Windows 用户安装；`Portable-x64.exe` 双击解压内置资源后启动。两者均可离线运行，无需 Node.js。`SHA256SUMS.txt` 用于校验下载。

升级前从托盘退出旧版。原来的设置自动保留；新增进度保存于 `%APPDATA%/ba-desktop-pet/care.json`，安装版与免安装版共用。
