# 1.13.0-beta.3 · 按需下载预览版

安装程序只包含程序本体、头像、家具缩略图和目录。首次启动选好语言，在角色目录点击想要的学生即可从 GitHub 下载模型与现有语音；下载完成后自动显示在桌面，可筛选「仅已下载」。

- Windows 安装包约 224 MB，安装后约 521 MB。爱丽丝与妮露合计额外下载约 12.6 MB；实际缓存占用以解压后的资源为准。
- 模型与语音分包。检查资源更新后，只下载发生变化的资源包，不必重下全部学生；家具按类别下载。
- 下载可以取消、失败可以重试；校验成功后才启用。已下载内容可离线使用，好感度和设置保留。
- 支持原有多学生、独立家具、双人／多人互动，以及中文、日文、英文界面。
- 完整版升级到轻量版时，如果没有资源缓存，需要重新下载所选学生一次。

此预览版的 Windows 安装版和免安装版经过真实 GitHub 下载、离线重启、多人家具、更新界面及打包内容检查。资源格式由 Windows 和 macOS 共用；macOS 安装包请以对应构建产物为准。

下载 Setup-x64.exe 安装，或使用 Portable-x64.exe。资源缓存位于应用用户数据目录中的 resources 文件夹；卸载程序保留用户数据。本应用未使用代码签名证书。素材来源与声明见仓库 THIRD_PARTY_NOTICES.md。
