# BA 桌宠 1.10.0 · 主动找老师

角色现在会偶尔停下来，向老师发出一个小邀约。点击角色或提示气泡，她会用原声回应，说完再继续活动。

- 为 38 名学生编排 73 组问好、陪伴和闲聊事件，引用本地原录音及对应字幕。比如爱丽丝请求摸头，千世邀请听俳句。
- 使用咖啡厅动作招呼老师、待机等待；45 秒没回应就自行继续，不扣羁绊。
- 首次约 1–2 分钟适合互动的在线时间后触发，此后间隔 5–10 分钟。设置中可关闭，或通过「试试主动互动」立即体验。
- 点击回应不触发物理抓取；真拖动、下落、求助、暂停、隐藏、休息和切换角色会让位给当前操作。
- 静音时仍显示字幕，音频失败也能正常结束；中文缺少完整组合时整组回退日语。
- 回复完成只按一次普通点击计算羁绊，保留冷却与每日限制。

## 下载与升级

`Setup-x64.exe` 为当前 Windows 用户安装；`Portable-x64.exe` 双击解压内置资源后启动。两者均可离线运行，无需 Node.js。`SHA256SUMS.txt` 用于校验下载。

升级前从托盘退出旧版。原来的设置和羁绊进度自动保留；主动找老师默认开启。
