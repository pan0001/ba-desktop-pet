# 1.13.3 · 修复当前伙伴不同步

## 简体中文

- **切换学生时同步左侧当前伙伴**：在「伙伴与活动」点亮学生卡片后，左侧头像、名字、羁绊和语音信息会跟随新选中的学生，不再停留在最早的主角色。
- **互动找对人**：「互动一下」、语音试听和羁绊照顾会作用于当前伙伴，避免头像换了、实际回应的还是另一位学生。
- **收起与重启保持一致**：收起当前伙伴后，自动显示仍在桌面的学生；全部收起时显示已收起状态，并禁用「互动一下」。重启会记住当前伙伴。从某位桌宠打开设置，也会显示她的信息。
- **保留多学生行为**：蓝色出现、灰色收起的操作不变；切换当前伙伴不会替换其他桌宠、重置位置或占用新的家具座位。额外学生暂不支持主动邀约，预览按钮会明确提示，避免误触发原主角色。

**更新方式**：Windows 安装版继续优先增量下载，缓存缺失或差分失败时回退完整安装包。保留设置、羁绊和已下载资源；本次没有修改角色或家具资源包，无需重新下载。便携版和 macOS 请手动下载并替换程序。

## 日本語

- 生徒カードを有効にすると、左側の「現在のパートナー」の画像・名前・絆・音声情報が、その生徒に切り替わるよう修正しました。
- ふれあい・音声プレビュー・お世話の対象も、表示中のパートナーに一致します。
- 現在の生徒をしまうと、デスクトップに残っている生徒を表示します。全員をしまった場合は、ふれあいボタンを無効にします。再起動後もパートナーを記憶し、生徒から設定を開くとその生徒を表示します。
- 複数生徒の選択・配置・家具の座席は維持します。追加の生徒は自分からのお誘いに未対応のため、プレビューは無効になり、その旨を表示します。

Windows インストール版は差分更新を優先し、必要に応じて完全版へフォールバックします。設定・絆・ダウンロード済みリソースは保持します。リソースパックの再ダウンロードは不要です。ポータブル版と macOS は手動で入れ替えてください。

## English

- Fix the current companion panel staying on the original student. Enabling a student card now updates the portrait, name, bond details and voice information together.
- Route interaction, voice preview and care actions to the displayed companion.
- When the current student is dismissed, show another student still on the desktop. Disable interaction when all students are dismissed. Remember the current companion across restarts, and show the corresponding student when opening settings from her desktop window.
- Preserve multi-student selection, window positions and furniture seats. Additional students do not yet support proactive invitations; their preview button now explains this limitation instead of triggering the original student.

Windows Setup continues to prefer differential downloads, with a full-download fallback. Settings, bond progress and downloaded resources are preserved. No character or furniture resource packs changed. Portable and macOS users should download and replace the application manually.
