# BA 桌宠 v1.12.0

新增设置 →「更新」：从 GitHub 检查正式版本，查看发布说明和下载进度。

- Windows 安装版支持增量下载，复用旧安装包中未变化的部分；无法增量下载时自动改为完整下载。
- 下载经过校验后，点击「重启并安装」保存桌宠状态并更新。检查更新不会自动下载，普通退出也不会安装。
- 默认启动后与每 6 小时检查，可关闭自动检查。
- Mac 按芯片类型提供新版下载入口，便携版提供对应 EXE 下载，均需手动替换。
- 修正素材按钮的重复边框和圆角裁切，保留原素材的斜边、透明边缘。
- 保留 1.11 的慢拖尺寸与抓取点修复、Windows 和 macOS 支持。

**首次升级**：1.11 及更早版本没有更新组件，请先手动安装本版 `Setup-x64.exe`。后续版本才能在桌宠内增量更新。更新不会删除已有设置和羁绊。

Windows 下载 Setup 安装版或 Portable 便携版。Mac 下载对应 arm64 / x64 的 DMG，拖入 Applications；仍为临时签名，尚无 Apple Developer ID 公证。Intel 运行验证使用 Rosetta，未在实体 Intel Mac 上验证。

`latest.yml` 与 `.blockmap` 是更新程序使用的元数据，不需要手动运行。所有包及更新元数据的 SHA-256 见 `SHA256SUMS.txt`。
