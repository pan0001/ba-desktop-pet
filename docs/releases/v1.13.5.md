# 1.13.5 · 补齐羁绊页面翻译

## 简体中文

- **修复羁绊页中外文混排**：照顾按钮、每日任务、奖励条件、成就名称与说明、等级称号和状态提示完整跟随中／日／英界面设置。
- **动态操作保持正确语言**：送礼、休息、冷却倒计时、次数用尽、经验增长和升级提示刷新后不再变回中文。
- **旧记录也能切换语言**：已有互动记录、成就记录及其中的羁绊加点、升级信息按当前语言显示；保留原始存档、羁绊数值和任务进度。记录时间格式与无障碍状态说明也跟随界面语言。
- 补齐侧栏暂停／隐藏状态和语音统计文案，修正日语配音选项中仍写着“中文字幕”的旧说明。

**更新方式**：Windows 安装版优先增量下载，旧缓存缺失或差分失败时回退完整安装包。保留设置、羁绊和已下载资源；角色、语音与家具资源包无需重新下载。便携版和 macOS 请手动下载并替换程序。

## 日本語

- お世話ボタン、今日の約束、報酬の条件、実績と説明、絆の称号、ステータス表示に中国語が残る問題を修正しました。
- プレゼント、休憩、待ち時間、回数制限、経験値やレベルアップの表示も、更新後に選択中の言語を維持します。

- サイドバーの一時停止・非表示の状態とボイス件数を翻訳し、日本語ボイスの選択肢に残っていた「中国語字幕」の説明を修正しました。

Windows インストール版は差分更新を優先し、必要に応じて完全版をダウンロードします。取得済みリソースの再ダウンロードは不要です。ポータブル版と macOS は手動で入れ替えてください。
