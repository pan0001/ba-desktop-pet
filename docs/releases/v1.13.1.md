# 1.13.1 · 伙伴多选与按钮更新

[简体中文 README](https://github.com/pan0001/ba-desktop-pet/blob/master/README.md) · [日本語 README](https://github.com/pan0001/ba-desktop-pet/blob/master/README.ja.md) · [English README](https://github.com/pan0001/ba-desktop-pet/blob/master/README.en.md)

## 简体中文

- 在「伙伴与活动」点击角色卡片：蓝色显示、灰色收起，最多 6 位；支持全部收起，重启恢复选择。未下载角色先完成下载再显示。
- 移除家具页重复的「添加学生」入口。收起入座学生会释放座位，家具保留。
- 按原游戏组件结构调整按钮：斜边底板、等比三角装饰、水平文字、轻阴影，不再拉伸纹理或叠加矩形边框。
- 包含游戏开发部沙发的外层旋转修复目录，保留正常内部动作。旧资源可单独检查资源更新。
- README 提供中文、日文、英文页面，顶部链接切换。

Windows 安装版在「更新」中检查 1.13.1，下载后选择「重启并安装」。优先复用旧安装包缓存进行增量下载；缓存缺失或差分失败时回退完整包。保留好感度、设置和已下载资源，不需要重新下载未变化的学生。界面变化需要程序更新，仅检查资源更新不会升级程序。

Mac 与便携版可检查新版，仍需手动下载对应文件并替换。Mac 尚未配置正式 Developer ID 签名和公证。

## 日本語

- 生徒カードで表示を切り替え：青は表示、グレーは非表示。最大 6 人、全員非表示と再起動後の復元に対応します。
- 家具タブの生徒追加メニューを整理。座っている生徒を非表示にすると席が空き、家具は残ります。
- ボタンを斜めの底板・等比の模様・水平の文字・軽い影で表示します。
- ゲーム開発部ソファ全体の回転修正と、3 言語を切り替えられる README を含みます。

Windows インストール版は差分取得を優先し、キャッシュがない場合や失敗時は完全版を取得します。設定・絆・リソースは保持します。画面変更には本体更新が必要です。Mac とポータブル版は手動で入れ替えてください。

## English

- Toggle student cards: blue shows a student, grey puts her away. Select up to six, deselect everyone, and restore selections on restart.
- Remove the duplicate add-student menu. Putting away a seated student frees the seat without removing furniture.
- Rebuild buttons with a slanted base, proportional patterns, horizontal labels, and subtle shadows.
- Include the Game Development Department sofa rotation correction and linked Chinese, Japanese, and English READMEs.

Windows Setup updates prefer differential downloads using the previous installer cache, with a full-download fallback when needed. Settings, bond progress, and resources remain intact. Interface changes require an app update. Mac and portable builds require manual replacement.
