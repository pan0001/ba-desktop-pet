# 伙伴多选与按钮显示

「伙伴与活动」里的角色卡片直接控制桌面学生：蓝色显示、灰色收起，最多六位，可全部收起。取消学生时同时释放家具座位。未下载的角色先完成资源下载，失败不会被选中。选择写入设置，重启恢复；旧存档默认保留原来的主学生。

移除了「语音与家具」里的添加学生下拉框和重复的学生管理列表，家具管理仍留在原处。主学生收起后不再参与移动、家具接近检测和陪伴计时，全局显示操作不会把已取消的主学生重新打开。

动作按钮使用 Common 图集的九宫格底板、10 度倾斜和等比的两侧三角装饰。文字保持水平，无额外矩形背景、边框或裁切。灰色是禁用操作，蓝色是常用操作，黄色是确认。学生卡片的蓝灰选择状态与操作按钮的禁用状态分别处理。

验证：112 项单元测试通过；实际 Electron 验证三学生开关、全部收起、重启恢复、家具中收起；多人家具回归通过；从公开 GitHub 下载两位学生并离线重启通过。按钮在中日英、1060 和 780 像素窗口下检查边缘、文字与禁用状态。
