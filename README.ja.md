# BA デスクトップペット

[简体中文](README.md) | **日本語** | [English](README.en.md)

『ブルーアーカイブ』の生徒たちがデスクトップにやってきます。散歩したり、頭をなでてもらったり、家具で過ごしたりしながら、作業中の先生に寄り添います。

**Windows x64** と **macOS 13 以降（Apple シリコン / Intel）** に対応。表示言語は中国語・日本語・英語から選べます。モデル・ボイス・家具は必要なものだけ GitHub からダウンロードし、取得済みのコンテンツはオフラインでも使えます。

[最新の正式版をダウンロード](https://github.com/pan0001/ba-desktop-pet/releases/latest) · [1.13.2 更新内容](docs/releases/v1.13.2.md) · [不具合を報告](https://github.com/pan0001/ba-desktop-pet/issues)

## ダウンロードとインストール

Node.js のインストールやソースコードの取得は不要です。環境に合わせて選んでください。

| 環境 | ファイル | 使い方 |
| --- | --- | --- |
| Windows x64 | `BA-Desktop-Pet-1.13.2-Setup-x64.exe` | 推奨。アプリ内の差分更新に対応します。 |
| Windows x64 | `BA-Desktop-Pet-1.13.2-Portable-x64.exe` | インストール不要。更新時は手動で入れ替えます。 |
| Apple シリコン Mac | `BA-Desktop-Pet-1.13.2-macOS-arm64.dmg` | 開いてアプリを Applications にドラッグします。 |
| Intel Mac | `BA-Desktop-Pet-1.13.2-macOS-x64.dmg` | 開いてアプリを Applications にドラッグします。 |

Mac 向けには ZIP も用意しています。配布ファイルには確認用の `SHA256SUMS.txt` を添付しています。正式なコード署名証明書は未導入です。Mac 版はアドホック署名のみで公証されていないため、OS によって起動が制限される場合があります。

## 初めて使うとき

1. 初回起動時に表示言語を選びます。ボイスは初期設定で日本語です。
2. 設定の生徒・活動タブで生徒を検索し、カードをクリックします。必要なリソースがなければ先にダウンロードします。
3. **青いカードは表示中、グレーのカードは非表示です。** もう一度クリックすると切り替わります。同時に最大 6 人、全員非表示にも対応します。選択は再起動後も復元されます。
4. ボイス・家具タブで家具を選び、好きな位置にドラッグします。対応する生徒が空席に近づくと自動で交流し、座っている生徒をダブルクリックすると離れます。

初期インストールには本体・カタログ・生徒の画像・家具のサムネイルが含まれます。全員をまとめて取得する必要はありません。ダウンロードは中止・再試行でき、「ダウンロード済みのみ」でオフライン利用できる生徒を絞り込めます。

## ふれあいと日常

- クリックすると反応し、頭の上でポインターを左右に動かすとなでられます。ボイス・字幕・ハートなどの感情エフェクトも出ます。
- ドラッグすると、つかんだ場所を支点に揺れ、髪が少し遅れて動きます。素早く動かして離すと慣性で飛んでいきます。
- タスクバー / Dock の上や、対応するウィンドウの上端を散歩します。高所から落ちると自力で起き上がったり、先生に助けを求めたりします。
- 家具は独立して最大 6 個配置できます。2 人・3 人の交流には対応する生徒が必要で、自由な組み合わせには対応していません。
- 好感度、気分、元気、満腹度、おやつ、プレゼント、実績、生徒からのお誘い。同じ生徒の別衣装は育成状況を共有します。
- 初期設定は日本語音声と対応する中国語字幕です。一部の中国語音声にも対応します。**表示言語を変えても字幕は翻訳されません。** 口の動き、カフェのモーション、エフェクトの切り替えもあります。

カタログには 276 の生徒・衣装エントリー、280 モデル、1015 個の家具があります。一部はモデルや日常ボイスが未対応です。[対応状況一覧（中国語）](docs/student-adaptation.md)をご覧ください。

生徒を右クリックするとメニューが開きます。Windows は通知領域のアイコンをダブルクリックして設定を開き、Mac はメニューバーのアイコンをクリックします。`Ctrl + Alt + B` / `⌘ + ⌥ + B` で表示を切り替えます。設定を閉じても終了しません。メニューの終了項目を使ってください。

## 差分・増分更新

| 更新する内容 | 操作 | 取得方式 |
| --- | --- | --- |
| 本体・機能・画面 | 設定の更新タブで更新を確認 | Windows インストール版は差分を優先。ポータブル版・Mac 版は手動で入れ替えます。 |
| モデル・ボイス・家具 | 「リソース更新を確認」の後、更新がある生徒や家具を選択 | 変更されたパックだけを取得し、変更のない取得済みパックは再利用します。 |

**Windows インストール版：** 前のインストーラーのキャッシュを利用して変更部分だけを取得します。キャッシュや旧 blockmap がない場合、または差分取得に失敗した場合は完全版の取得に切り替えます。検証後に再起動・インストールを選ぶと、設定・リソース・絆を保持して更新します。確認だけでは自動取得せず、通常の終了時にも勝手にインストールしません。1.11 以前からは、現在の Setup 版を一度手動でインストールしてください。

**リソース：** パック単位の増分更新で、GLB 内部のバイナリ差分ではありません。家具は種類ごとにまとめて取得します。SHA-256 検証に通ったパックだけを使用します。1.13.2 のカード操作やボタン変更には本体の更新が必要です。リソース更新だけでは画面は更新されません。

**Mac / ポータブル版：** 新版の確認はできますが、対応する配布ファイルを取得して手動で入れ替えてください。Mac の自動差分インストールにはまだ対応していません。

## データとトラブル対処

Windows の保存先：`%APPDATA%/ba-desktop-pet/`。Mac：`~/Library/Application Support/ba-desktop-pet/`。

設定は `settings.json`、育成状況は `care.json`、取得済みリソースは `resources/` に保存します。更新・再インストール時にこれらを意図的に削除することはありません。リソース削除前に使用中の生徒や家具をしまってください。モデルを削除しても絆は残ります。アプリを入れ替える前に旧版を終了してください。

生徒が見つからないときはカードが青か、一時停止や非表示になっていないかを確認し、元の位置に戻す機能をお試しください。不具合の報告には OS、バージョン、再現手順、画像を添え、個人情報を含むセーブデータは投稿しないでください。

## 開発

Node.js 22.12 以降が必要です。Mac のローカルビルドには Xcode Command Line Tools も必要です。

```sh
npm ci
npm run build:native
npm start
npm test
```

Windows は `npm run release:win`、Mac は `npm run release:mac`。出力先は `dist/releases/v1.13.2/`、標準はリソースを必要に応じて取得する構成です。ビルドだけでは公開されません。詳しい操作・開発手順は[詳細ガイド（中国語）](docs/guide.zh-CN.md)をご覧ください。

正式公開時には旧 Setup / blockmap を保持し、新しい配布ファイル、`latest.yml`、blockmap をアップロードしてチェックサムを確認します。メタデータの手動取得は不要です。3 種類のビルドとパッケージ起動検証が成功してから公開します。
