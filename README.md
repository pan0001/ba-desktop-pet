# BA 桌宠

**简体中文** | [日本語](README.ja.md) | [English](README.en.md)

让《蔚蓝档案》的学生来到桌面：散步、摸头、聊天、使用家具，也可以一起陪老师工作。

支持 **Windows x64** 和 **macOS 13+（Apple 芯片 / Intel）**，界面提供中文、日文、英文。模型、语音、家具按需从 GitHub 下载，已下载内容可离线使用。

[下载最新正式版](https://github.com/pan0001/ba-desktop-pet/releases/latest) · [1.13.1 更新说明](docs/releases/v1.13.1.md) · [反馈问题](https://github.com/pan0001/ba-desktop-pet/issues)

## 下载与安装

无需安装 Node.js，也不用下载源码。在正式发布页按系统选择：

| 系统 | 文件 | 使用方式 |
| --- | --- | --- |
| Windows x64 | `BA-Desktop-Pet-1.13.1-Setup-x64.exe` | 推荐。支持应用内增量更新。 |
| Windows x64 | `BA-Desktop-Pet-1.13.1-Portable-x64.exe` | 免安装，升级时手动替换。 |
| Apple 芯片 Mac | `BA-Desktop-Pet-1.13.1-macOS-arm64.dmg` | 打开后拖入 Applications。 |
| Intel Mac | `BA-Desktop-Pet-1.13.1-macOS-x64.dmg` | 打开后拖入 Applications。 |

Mac 同时提供对应 ZIP。发行文件附 `SHA256SUMS.txt`。程序尚未使用正式代码签名证书；Mac 使用临时签名、未公证，系统可能阻止直接打开。

## 第一次使用

1. 启动后选择界面语言，语音默认日语。
2. 设置 → **伙伴与活动**，搜索学生并点击角色卡片。缺少资源时先下载。
3. **蓝色：在桌面显示；灰色：收起。** 再点一次即可切换，最多同时 6 位，也可以全部收起。重启恢复选择。
4. 在 **语音与家具** 选择家具，拖到合适位置。兼容学生靠近空位会自动互动；双击入座学生可以离开。

首次安装只包含程序、目录、头像与家具缩略图，不必下载全部学生。下载可取消、失败可重试；「仅已下载」可筛选离线可用的角色。

## 陪伴与互动

- 点击回应；鼠标在头部来回轻拂可摸头，伴随原声、字幕和情绪特效。
- 按住人物拖动，以抓取点为支点摆动；快速甩动后松手有惯性，头发滞后回摆。
- 在任务栏 / Dock 上方或支持的窗口顶边散步。高处落下可能自己起身，也可能请求帮助。
- 同时摆放 6 件独立家具。适配的双人、三人互动需要对应学生，不能任意组合。
- 好感度、心情、精力、饱腹、点心、礼物、成就与主动邀约。同一学生不同形态共用养成进度。
- 默认日语原声和对应中文字幕，支持部分中文配音。**界面语言不等于字幕翻译语言。** 提供说话嘴型、咖啡厅动作和特效开关。

目录包含 276 个角色／换装、280 个模型与 1015 件家具。部分角色仍缺模型或日常语音，见 [学生适配清单（中文）](docs/student-adaptation.md)。

右键学生打开菜单。Windows 双击通知区图标打开设置；Mac 点击菜单栏图标打开菜单。`Ctrl + Alt + B` / `⌘ + ⌥ + B` 显示或隐藏。关闭设置不会退出程序，请使用「退出桌宠」。

## 增量更新

| 更新内容 | 入口 | 下载方式 |
| --- | --- | --- |
| 程序、功能、界面 | 设置 → **更新** → **检查更新** | Windows 安装版优先增量；便携版和 Mac 手动替换。 |
| 模型、语音、家具 | **检查资源更新**，再选择有更新的角色或家具 | 只下载变化的资源包，复用未改变的已安装包。 |

**Windows 安装版：** 点击下载后复用旧安装包缓存，只下载变化的文件块；缺少缓存、旧版 blockmap 或差分失败时回退完整安装包。校验后点击「重启并安装」，保留设置、资源与羁绊。检查更新不会自行下载，普通退出不会自动安装。1.11 及更早版本需先手动安装当前 Setup 版一次。

**资源更新：** 属于资源包级增量，并非 GLB 内部差分。家具按类别共用下载，SHA-256 校验通过才启用。1.13.1 的角色卡片和按钮变化属于程序更新，仅检查资源更新不会升级界面。

**Mac / 便携版：** 可以检查新版，但仍需手动下载对应文件并替换。当前不支持 Mac 自动增量安装。

## 数据与排错

Windows 数据目录：`%APPDATA%/ba-desktop-pet/`；Mac：`~/Library/Application Support/ba-desktop-pet/`。

`settings.json` 保存设置，`care.json` 保存养成进度，`resources/` 保存下载资源。升级或重新安装不会主动删除这些文件。移除资源前先收起使用它的学生或家具；移除模型不删除羁绊。替换程序前先退出旧实例。

找不到学生时，确认卡片为蓝色，检查暂停／隐藏状态，并尝试「找回桌宠」。反馈请附系统、版本、复现步骤和截图，不要上传含个人信息的存档。

## 开发

需要 Node.js 22.12+；Mac 本机构建还需要 Xcode Command Line Tools。

```sh
npm ci
npm run build:native
npm start
npm test
```

Windows：`npm run release:win`；Mac：`npm run release:mac`。产物在 `dist/releases/v1.13.1/`，默认按需下载版，本地构建不会自动发布。更多操作与开发说明见 [详细指南（中文）](docs/guide.zh-CN.md)。

正式发布保留旧版 Setup / blockmap，上传新版安装包、`latest.yml` 和 blockmap，并核对校验和。用户无需手动下载这些更新元数据。三平台构建及打包运行检查通过后才公开发布。
