# BA 桌宠 1.13.0

Windows x64 与 macOS 13+（Apple 芯片 / Intel）本地 3D 桌宠。当前正式版接入 276 个角色／换装、280 个模型，保留原有角色与好感度存档。模型、语音和家具按需从 GitHub 下载；已下载的资源与桌宠交互可离线使用。这是非官方同人应用，素材与组件说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 按需下载

默认安装包只带程序、头像、家具缩略图与目录。在角色卡片点击「下载」，会自动下载该角色模型及现有配音；可勾选「仅已下载」筛选。家具按类别下载。中日英界面均可用。

「检查资源更新」仅获取目录，点击有更新的角色或家具才下载变化的模型／语音／家具包；这是资源包级增量，不是 GLB 内部二进制差分。下载可取消、失败可重试，SHA-256 校验通过才启用。缓存位于应用用户数据目录的 `resources` 子目录，重新安装程序不会删除缓存、好感度或设置。下载资源可移除；请先收起占用该资源的学生或家具。完整版升级为轻量版后，如没有缓存需重新下载所选角色一次。

开发打包默认轻量版，`node tools/release.cjs dir --full-assets` 可保留所有素材。更新资源时运行 `node tools/build-resource-packs.cjs`，核对变更后执行 `node tools/publish-resource-packs.cjs`；该命令上传不可变资源包并在全部校验通过后发布目录。

## 1.13 学生适配预览

学生身体模型统一采用古书馆处理过的版本，配套头像、中日英名字和搜索、10,036 条日常语音，以及 270 个角色的主动邀约。首次启动选择界面语言，语音默认日语。桌宠运行时适配面部材质、嘴型及光环跟随，不修改下载的原始 GLB 文件。

当前古书馆仍缺 5 个已实装角色／换装的身体模型，6 个已接入角色暂无可用日常语音。完整名单、来源和验证说明见 [学生适配清单](docs/student-adaptation.md)。本地 Windows 程序位于 `dist/releases/v1.13.0/win-unpacked/BA-Desktop-Pet.exe`，复制时需保留整个目录。以下 GitHub 下载说明仍对应已发布的 1.12 稳定版。

## 1.12 GitHub 增量更新

设置 →「更新」或托盘 →「检查更新」查看新版和发布说明。默认启动后及每 6 小时检查一次，可在设置关闭。不会自动下载，也不会在普通退出时自行安装。

Windows **安装版**点击「下载更新」后，优先复用上次安装包的缓存，只下载变化的文件块；缺少缓存、旧版 blockmap 或差分失败时回退完整包。SHA-512 校验及 GitHub 提供的 SHA-256 校验通过后，点击「重启并安装」保存设置与羁绊、更新当前用户的安装并重新启动。实际节省量取决于变化内容和压缩结果。

**1.11 及更早版本需要先手动安装一次 1.13.0 安装版**，之后的新版本才支持应用内更新。便携版与 Mac 版提供检查和对应下载入口，仍需手动替换；Mac 自动安装需后续配置稳定的 Developer ID 签名。源代码版不会自动修改 Git 工作区。

发布时保留旧版 Setup 和 blockmap，并上传新版 `latest.yml`、`Setup-x64.exe.blockmap` 及全部安装包；工作流校验所有文件后才公开发布。用户只需下载安装包，不必手动下载这些更新元数据。

## 1.11 跨平台与拖动修复

修复 Windows 分数缩放下移动窗口反复取整导致的累计放大。窗口移动使用固定的目标尺寸，模型画布也保持固定，避免慢拖时抓取点漂移、镜头反复适配以及异常放大后行走时不断调整透明窗口。

Mac 版提供 `macOS-arm64.dmg`（Apple 芯片）和 `macOS-x64.dmg`（Intel），也可下载对应 ZIP。打开 DMG 后将应用拖入 Applications。Mac 菜单栏图标可打开菜单，`⌘ + ⌥ + B` 显示或隐藏桌宠；地面为 Dock 上方，可读取其他窗口的顶边作为平台。Mac 包使用临时签名，尚未配置 Apple Developer ID 签名及公证，因此系统可能阻止直接打开。

Mac 数据保存在 `~/Library/Application Support/ba-desktop-pet/`。在 Mac 开发机上安装 Node.js 22.12+ 和 Xcode Command Line Tools，执行 `npm ci`、`npm run release:mac`；会构建当前 Node.js 架构的 DMG 和 ZIP。GitHub Actions 在 Windows 和 Apple 芯片 Mac 上构建并启动成品，Intel 版在 Apple 芯片 Mac 上通过 Rosetta 检查，使用默认图形后端。Intel 实机、多屏和全屏空间仍需对应设备验证。

| --- | --- |
| `BA-Desktop-Pet-1.13.0-Setup-x64.exe` | 安装版：按向导选择安装目录，仅为当前 Windows 用户安装，从开始菜单启动。 |

轻量版首次运行显示设置面板，在角色目录点击下载想要的角色，下载完成后显示桌宠。关闭设置面板后桌宠继续运行。

## 操作

- 设置 →「羁绊」可以查看好感成长、心情、精力、饱腹、今日小约定和成就，并给点心、送礼物、一起玩或休息；右键菜单也有照顾入口。
- 点击角色：播放咖啡厅 Cafe_Reaction，结束后继续 Cafe_Idle；载具形态缺少咖啡厅动作，保留自身待机。
- 在头部来回轻拂鼠标（无需按键）：摸头，出现爱心并播放回应语音。按住仍然是拖动，头发本身不接收命中。
- 摸头冒出粉色爱心，点击散出星光，提起、扶起与落地也有短暂的小特效。设置 →「伙伴与活动」→「互动小特效」可关闭；暂停、隐藏或换角色会立即清理，系统开启减少动态效果时也不播放。
- 原版情绪符号跟随头部：摸头显示爱心，连续几次摸头会害羞；点击显示闪光或问号，提起显示惊叹号，抛出冒汗，躺着求助显示困扰、扶起后显示爱心，欢迎和挂机说话时冒出音符。沿用「互动小特效」开关。
- 默认日语原声和对应中文字幕；点击、摸头、提起以及挂机分别使用日常语音。设置 →「语音与家具」可以调音量、切换中文配音、试听、关闭声音或调整挂机频率。默认约 2–4 分钟随机说一句，同一时刻只播放一句。
- 设置 →「语音与家具」→「桌面休息角」可搜索、翻页选择 1015 件原始家具。支持同时 6 位学生、6 件独立家具；108 组原作专用互动中含 5 种双人或三人家具。兼容学生靠近空位自动互动，双击入座学生可离开，家具留在原地。名单与位置自动保存。
- 按住角色拖动：以鼠标实际抓住的位置为支点提起；身体悬挂摆动，头发滞后回摆，停止后逐渐稳定。提起使用素材中的 Pickup 动作。
- 快速甩动后松开：向上抛会继续上升后落下，向左、右抛会沿弧线飞出；停止移动片刻再松手则正常放下。「拖动惯性与发丝」开关也控制抛掷；关闭自主散步仍然可以抛掷，落地后留在原地。
- 抓取脸部、身体或服装，头发不接收点击、不参与地面或窗口碰撞；头发下方若有身体，鼠标可穿过头发抓住身体。
- 开启「自主散步」后，松手会落到下方可站立的窗口顶边或任务栏上方；走走停停，到边缘转身。开启「站在窗口上」后才会把其他窗口作为平台。
- 把角色脚底放在窗口顶边附近（约 34 像素范围）可直接站上去；窗口顶边需要有足够空间容纳角色。窗口移动时角色随平台移动；窗口关闭、最小化或边缘被遮住时重新下落。
- 明显高处落地后随机触发：45% 倒地后自己起身、35% 快速起身、20% 躺着显示「老师，帮我一下」。点击求助气泡或角色即可扶起，然后恢复咖啡厅待机与散步。小幅放下不触发；暂停时等待继续。
- 右键角色：打开菜单，可切换角色、暂停、隐藏、找回或退出。
- 双击 Windows 通知区的蓝色光环图标：打开设置。图标可能在通知区的折叠区域中。
- `Ctrl + Alt + B`：显示 / 隐藏桌宠（快捷键未被其他程序占用时）。
- 设置面板支持中文、日文或英文名搜索、角色选择、220–560 的角色显示大小调整和置顶开关。透明画布比角色大，四周留有武器及摆动空间。
- 角色周围的透明区域允许鼠标点击穿透；说明提示显示期间会占用其小块区域。
- 退出请使用托盘菜单或设置面板的「退出桌宠」。重复启动会唤回已运行的实例。
- 右键「恢复待机动作」可以退出特殊动作，重新开始待机。明确开启的「暂停动画」也会暂停散步，下落和发丝模拟。

角色选择、大小、位置、置顶、暂停、惯性和行走开关会保存在 Windows 用户数据目录中（默认 `%APPDATA%/ba-desktop-pet/settings.json`）。不会写回 PAWEB，也不会修改原模型。

## 1.10.1 动态嘴型

说话时根据正在播放录音的音量，在闭嘴、小口、半开与张口之间变化；语音停顿、结束、静音、暂停或隐藏时自然闭嘴。互动时短暂微笑。复用原嘴部图集，眼睛与原模型动画保留，不是逐音素口型识别。只在原有渲染帧中更新 UV，不逐帧上传贴图。

## 1.10 主动找老师

角色偶尔停下来发出小邀约，配合一次咖啡厅回应动作，再保持待机等老师。点击角色或头顶提示气泡后，播放对应的原声回复和中文字幕，说完恢复日常活动。连续点击不会重复排队，回应完成按一次普通点击计算羁绊，仍遵守原有冷却与每日上限。

已为 38 名学生整理 73 组日常事件，包括问好、陪伴与闲聊。邀请与回复直接引用本地语音目录的原录音和字幕；没有合适邀请录音时，用提示气泡发起。例：爱丽丝请求摸头、千世邀请听俳句。它们是桌宠依据台词编排的小互动。中文缺少完整组合时整组回退日语，避免混合语言。

首次累计 1–2 分钟适合互动的在线时间后触发，之后间隔 5–10 分钟；说话、特殊动作与拖拽期间不发起。45 秒没有回应会自行继续，不扣羁绊。隐藏、暂停、锁屏、休息、使用家具、精力低于 25 或角色切换会取消/暂缓邀约。关闭声音仍能看字幕回应；音频失败也会以字幕完成。

设置 →「语音与家具」→「她的小邀约」可以关闭主动找老师，或点击「试试主动互动」立即体验。试用也要等当前语音、拖拽或特殊动作结束。

## 1.9 羁绊与日常照顾

每名学生有独立的 1–10 级羁绊和称号，同一学生编号的不同模型共用进度。羁绊由有效点击、摸头、扶起、礼物与陪伴积累，离线不会下降。每天的普通互动最多增加 40 点、陪伴最多增加 12 点；点心、礼物和今日奖励另有次数限制。

| 行为 | 效果与限制 |
| --- | --- |
| 点击 / 摸头 / 扶起 | 羁绊 +2 / +3 / +3，分别冷却 30 / 20 / 60 秒；有效扶起才计数 |
| 给点心 | 每天 3 次，冷却 45 秒；饱腹 +30、精力 +10、心情 +8、羁绊 +5；饱腹达到 90 时不消耗次数 |
| 送礼物 | 每天 1 次，心情 +15、羁绊 +15 |
| 一起玩 | 冷却 60 秒，精力 -10、心情 +12、羁绊 +5；精力不足或休息中不可用 |
| 休息一下 | 暂停自主散步，每有效陪伴分钟恢复 8 精力；恢复满后自动结束，也可手动结束 |
| 今日小约定 | 打招呼一次、摸头一次、陪伴五分钟，完成后可领取一次羁绊 +10 |

只有角色已加载、可见、未暂停且电脑未锁屏时计算陪伴。正常活动每分钟缓慢消耗 0.4 精力和 0.3 饱腹，休息时消耗 0.2 饱腹；未互动时心情逐渐靠近舒适值。隐藏、暂停、锁屏和离线都不会补算时间或扣好感。

精力低于或等于 20 时暂时不自主散步；低于 30 时挂机语音间隔加倍，休息期间停止自动闲聊。恢复后继续使用原来的行走和语音设置。升级优先播放角色真实的 `Relationship_Up` 台词与字幕，缺失时使用日常回应；照顾反馈不会抢占拖动、下落或求助动作。

成就包括初次交流、小小心意、相伴一小时和羁绊三级，并记录最近八条照顾经历。进度单独保存，损坏的 JSON 会尽可能保留备份；普通设置不受影响。系统没有付费道具、疾病、死亡或连续签到惩罚。

设计参考了 [VPet 的状态与食物联动](https://github.com/LorisYounger/VPet/blob/main/VPet-Simulator.Windows.Interface/GameSave_VPet.cs)、[DyberPet 的好感与动作配置](https://github.com/ChaozhongLiu/DyberPet/blob/main/docs/art_dev.md)和 [Desktop Mate 的鼠标陪伴交互](https://store.steampowered.com/app/3301060/Desktop_Mate/)。以上数值与规则是本项目的实现，未复制这些项目的代码。

## 1.7 原版情绪符号

从本机此前「连接 MuMu 模拟器 ADB」对话解包的 `BlueArchive_UI` 中选出 16 张 Emoticon／Emoji 原图，复制到 `assets/emotions`，保留原文件字节、来源与哈希。没有改动原解包文件，也不依赖模拟器或外部文件夹。

将其中的爱心、害羞、闪光、问号、惊叹号、汗滴、困扰和音符接入桌宠事件。主情绪符号一次显示一个，使用实际头骨投影跟随动画与拖动；轻微弹出、浮动和淡出，图片只解码一次，和粒子共用按需绘制。求助、抛出等较重要的反应不会被普通点击或挂机音符盖掉。

这里复用的是游戏原版图片，触发规则和播放动画由桌宠实现；解包预制体引用的外部动画片段未包含在现有 JSON 中，没有声称完整还原原作时间轴。素材说明及预览见 `assets/emotions/README.md`、`assets/emotions/preview.html`。嘴型、眼睛、Cafe 动作和头发碰撞规则沿用现有实现。

## 1.6 抛掷惯性

松手时根据最近一小段鼠标移动计算出手速度，受到重力与空气阻力后逐渐落地。屏幕边缘有衰减回弹和顶部限位；高度允许时可在横向相邻的显示器之间继续飞行。向上飞时穿过窗口顶边，回落时才会站上平台，并保留原有倒地／起身／求助反应。

轻放、停住再松手不会突然弹走。切换焦点、取消拖动或隐藏桌宠不触发抛掷；暂停会冻结飞行，再次抓取可以中止惯性。沿用非头发碰撞范围及现有鼠标支点。

## 1.5 性能与互动特效

互动特效使用本地绘制的爱心、星星、闪光和轻尘，最多同时保留 40 个粒子，约 30 帧更新；播完就停止刷新，不占用鼠标命中范围。连续点击有冷却，不会无限积累特效。

静止时不再重复发送相同运动状态，位置没变也不再定时重写设置文件。鼠标命中与头部判断共用一次查询，隐藏的字幕不再逐帧读取布局。保持现有画布边距、动作帧率和非头发碰撞规则。

骨骼矩阵按姿态预先计算，地面支撑与射线检测复用精确顶点结果，不缩减模型。当前机器以光、320 大小对比 1.4：渲染线程待机工作时间约下降 38%，鼠标悬停在身体时约下降 90%。测量方式及数据见 `VERIFICATION.md`。

## 1.4 语音、摸头与家具

从基沃托斯古书馆的公开学生数据取得 38 名角色的日常音频及对应台词，收录 786 句日语与 671 句中文，全部保存在本地。中文覆盖 34 名角色，缺少时自动使用同一角色的日语与对应翻译。音频、台词、语言和来源按单条记录绑定；不把战斗喊声、生日或其他节日限定语音混入普通挂机。

播放有冷却和连续重复规避，不积压语音队列。暂停、隐藏、切换角色会停止当前语音；挂机台词只在待机、散步或家具休息时触发。语音不会代替模型的 Cafe 动作，也不需要联网或 AI 服务。

家具已使用本地游戏完整 prefab 导出的原始模型替换早期简模。共开放 1015 件摆放家具，103 个学生/服装的 108 组专用互动；缺失、裁剪和接触位置异常的组合不开放专用互动。实际渲染核查、来源与限制见 `docs/furniture-adaptation.md`、`assets/furniture/README.md`。

## 1.1 更新

在透明窗口、30 帧动画、角色互动和托盘管理基础上，加入身体惯性、发丝弹簧、重力落地、自主散步、窗口平台识别与跟随。39 个模型带有走路动画；柯伊的载具形态没有适合的走路动作，落地后留在原地。

动画使用循环待机，单次互动结束后自动回到待机，松开拖动后释放提起姿势；关闭透明窗口遮挡引起的自动渲染节流，隐藏/锁屏仍显式暂停。桌面使用正交视角和支撑脚高度修正，减少走路时的漂浮感。

发丝是叠加在原动画上的骨骼弹簧模拟，尚无逐发丝碰撞，极端甩动时个别角色可能轻微穿模。窗口平台只使用可见且有足够上方空间的普通窗口顶边；任务栏自动隐藏时沿屏幕工作区底部行走。未加入聊天、开机启动或多角色同屏；角色语音已在 1.4 加入。

窗口检测组件只读取窗口几何位置和可见状态，不读取窗口内容，不截图、不发送鼠标或键盘输入。检测不可用时自动保留任务栏行走，并在设置中显示提示。

## 1.2 更新

抓取支点随鼠标选中的骨骼附件固定，提起姿势变化时也不会围着脚底打转。日常出场、待机、走路和点击互动优先采用 Cafe 系列，不再插入 Victory 展示动作。

高处落地增加三种概率反应，求助期间停止行走，扶起完成后继续活动。素材没有独立起身动画，使用倒地动画反向采样生成起身；快速恢复使用其中较短的站起部分，不修改原 GLB。躺下时按当前模型最低处贴合平台。没有倒地素材的载具形态平稳落地。

移动窗口前检查坐标有效性，异常时自动找回桌宠，避免无效坐标进入 Windows 接口；过滤异常平台数据。原截图错误的具体触发条件尚未复现，已验证注入无效坐标可自动恢复。

## 1.3 修正

头发材质从鼠标命中与落地支撑中排除，几何范围只统计实际被三角形引用的顶点。头发仍参与显示和惯性摆动。

抓取改为跟随实际点击的蒙皮三角形表面，刷新骨骼与绑定矩阵后围绕该点旋转；迟到的主进程运动消息不再取消本地抓取。自动测试覆盖真实 pointerdown、IPC、窗口移动和渲染全过程。

透明画布扩大为逻辑角色大小的 2.6 倍，保持角色在屏幕上的像素大小。武器和摆动不再受原来的小方框限制。落地范围、行走速度和窗口上方所需空间按角色大小计算，新增透明边距不参与碰撞；旧位置在升级时自动迁移。

已复现 1.2 的窗口坐标报错：`Math.round(-0.1)` 返回 `-0`，Electron 的原生整数接口拒绝该值。自动行走、拖动、定位和保存的坐标现统一取整并将 `-0` 转为普通 `0`；通过实际窗口接口和 movementTick 跨越零点的回归验证。

## 1.3.1 地面动作修正

修正模型初始贴地高度被重复缩放的问题。站立、下落、倒地、起身和走路统一使用最终姿势的非头发接触范围；贴地修正在身体旋转之后计算，避免动作切换时突然上下跳动。

水平定位统一跟随骨骼根节点，不再在倒地/起身时按变化的包围盒重新居中。起身动画的开头和结尾增加缓动；松手时保留当时的身体位置和角度，再平滑衔接下落，避免重置抓取偏移造成跳动或瞬间反向倾斜。头发仍不参与碰撞，鼠标表面支点与武器显示空间保留。

其他窗口遮挡平台时，以平台窗口的实际位置判断移动，不再把可见边缘的变化当成窗口移动；脚下被遮住时自然下落。

## 开发与验证

在 Windows x64 上安装 Node.js 22.12+ 后：

```sh
npm ci
npm run build:native
npm start
npm test
npm run test:desktop
node tests/dynamics-desktop.cjs
node tests/landing-desktop.cjs
node tests/grab-desktop.cjs
node tests/ground-desktop.cjs
node tests/companion-desktop.cjs
node tests/furniture-desktop.cjs
node tests/coordinates-desktop.cjs
node tests/packaged.cjs
npm run pack
```

制作可分发程序：

```sh
npm run release:win
node tests/release-smoke.cjs
```

安装版、免安装版及 `SHA256SUMS.txt` 输出到 `dist/releases/v1.13.0/`。Windows 的 `npm run release:zip` 可额外构建完整程序目录的 ZIP；Mac 使用 `npm run release:mac`。本地构建命令不会自动上传 GitHub。源码仓库不提交生成的安装包、开发依赖、测试用户数据或日志。

发行静态检查会校验资源、许可证和 SHA-256，解包核对安装版与免安装版的应用内容；不会执行系统安装或修改用户配置。真实界面可用 `node tests/settings-ui.cjs "dist/releases/v1.13.0/win-unpacked/BA-Desktop-Pet.exe"` 在隔离配置下验证。

`node tests/platform-desktop.cjs --packaged` 在当前平台启动打包程序、验证设置和原生窗口读取。Windows 可用 `node tests/slow-drag-desktop.cjs --force-device-scale-factor=1.25` 重现分数缩放环境并检查移动不累计放大。GitHub 的 `Publish verified desktop packages` 手动发布流程只接受三平台均成功的构建 run ID，核对六个安装包及上传后的 SHA-256，再公开 Release。

`tools/build-catalog.cjs` 从资源索引和 GLB 动画生成可选角色清单；`tools/make-icon.cjs` 生成程序图标；`tools/build-native.cjs` 在 Windows 使用系统 C# 编译器，在 Mac 使用 Swift 编译只读窗口几何组件。

`tests/desktop.cjs` 启动真实 Electron，检查角色互动恢复、设置操作、40 个模型的 WebGL 加载、错误输出和保存结果；截图与报告输出到 `test-results`。测试使用独立用户数据目录。`tests/native-desktop.cjs` 用于真实 Windows 鼠标操作检查。

代码结构：`electron/` 管理窗口、平台行走与本地设置，`native/` 读取 Windows/macOS 窗口几何，`renderer/` 管理交互及设置界面，`scripts/` 管理 3D 渲染、动画和发丝弹簧。仅允许应用自有资源通过 `pet://app` 加载，渲染进程不提供 Node.js 权限。
