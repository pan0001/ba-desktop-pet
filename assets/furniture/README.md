# 桌面家具

`catalog.json` 和 `icons/` 来自基沃托斯古书馆公开的学生家具关联与道具数据；本次下载 31 张关联家具参考图。爱丽丝对应道具 937「游戏开发部的沙发」与 837「格斗游戏机」。

2026-09-25 检查公开模型分页目录，共 533 个条目，类型为 315 个 body 和 218 个 halo，没有家具模型。道具接口提供名称、说明、图标及关联学生，没有三维模型下载字段。原角色 GLB 也未附带这两件家具。

当前 `models/` 已改为用户已有游戏完整 prefab 导出的原始 GLB，替换早期简模。`models.json` 保留来源 bundle、SHA-256、动画、学生关联和排除原因；原始模型与贴图不改写，共 389,099,816 字节。

1052 个来源条目中 1016 个导出成功，排除 1 个无贴图模型，最终 1015 件可摆放。36 个导出失败条目保留在 `excluded`。108 组学生/家具组合启用专用互动，失败组合仅保留摆放，不使用其他学生的动作替代。`previews/` 是实际桌宠画面的裁切缩略图。家具暂用中日英分类及稳定编号命名，沙发和游戏机保留旧 ID。

运行时适配导出坐标轴、原始 alpha 数据与共享动画坐标。GLB 没有完整保留 Unity 特效、机台屏幕程序及特殊 shader。适配方法、核查流程和限制见 `docs/furniture-adaptation.md`。

参考资源保留在语音同步索引的文件列表中，包含原始 URL 和 SHA-256；原图和角色素材的权利归原权利人所有。
