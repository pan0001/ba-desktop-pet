# 主动邀约台词编排

`initiatives.json` 为桌宠的“主动招呼 → 等待点击 → 回应”选择现有语音。当前覆盖 270 个角色／换装、305 个事件，分为打招呼、陪伴和闲聊；包含 305 对日语条目、254 对中文条目。原有 73 组手工编排保留；新增角色采用无语音的等待提示，点击后播放本人的完整日常台词，避免拼凑虚假的对话顺序。素材来源与下载索引沿用本目录 [README](README.md) 和 [catalog.json](catalog.json)，录音及对应中文字幕来自基沃托斯古书馆整理的游戏语音。

每个事件只引用 `catalog.json` 中本学生、本语言的真实 `line.id`，播放整个原始 Ogg，字幕也直接使用该条目的 `text`。没有合成配音、改写原台词或拼接音频。优先使用 Cafe、Lobby、LogIn 和 Relationship_Up 日常条目，不使用战斗、编队展示、活动商店或节日专用台词。

这套“何时主动开口、等待多久、点击后接哪一句”的机制是桌宠自行编排，不代表原游戏中存在完全相同的连续剧情。`label` 和 `prompt` 是桌宠界面文字，不是录音字幕。比如“点击夸夸日奈很可爱”明确了点击的含义，再接原有的害羞回应。

部分对照例子：

| 学生 / 事件 | 邀请的原条目 | 回应的原条目 |
| --- | --- | --- |
| 爱丽丝 / 摸摸头 | `Aris_Cafe_Act_5`：请摸摸爱丽丝的头吧…… | `Aris_Relationship_Up_4`：能和老师相遇，爱丽丝很幸福！ |
| 临战爱丽丝 / 我在等你 | `ch0334_login_2_1`：老师，等您很久了！ | `ch0334_login_2_2`：没关系！爱丽丝不管多久都愿意等下去！ |
| 千世 / 听首俳句 | `Chise_Lobby_4`：询问老师是否想听俳句 | `Chise_Lobby_5`：午饭我吃了，鸡肉做的天妇罗，名古屋美食。 |
| 柯伊 / 生活提醒 | `ch0335_lobby_3_1`：借此机会，请允许我说一句。 | `ch0335_lobby_3_2`：你有好好吃饭吗？适当的运动也是必要的。 |

254 个事件使用 `invite: null`；界面先显示等待提示，点击后才播放真实回应。没有为凑齐邀请而借用不相关台词。

`languages.jp` 始终是一整对可用引用。只有本事件的中文邀请和回应都可用时才提供 `languages.cn`；无语音邀请的事件则只需中文回应。缺中文的临战爱丽丝、柯伊、胡桃和妮可由运行时整对回退日语，不能把日语邀请与中文回应混成一对。

验证：`node --test tests/initiative-catalog.test.cjs`，检查学生覆盖、事件结构、同学生同语言引用、原条目类别、本地 Ogg 文件头以及跨语言整对关系。更新语音目录后也应重新运行这项验证。
